# Original frontend reference, not a deployment

These three files are unchanged copies of the owner-supplied prototype frontend. They are included so the local agent can inspect and reuse useful code. Their original student JSON and Python backend are intentionally absent.

**Do not run or publish this as the finished product.** It depends on local endpoints and personal-course assumptions, and its connection/save labels are not a hosted authentication or persistence implementation. Use a dedicated new application directory and static output. Keep these files out of deployment assets.

See `../../docs/06-SOURCE-REVIEW.md` for known observations and limits of the review. SHA-256 hashes in `../../MANIFEST.json` allow verification that these copies were not modified in the handoff.

# Private whole-account Canvas capture

## Decision and verified baseline

Marymount OAuth approval and a replacement personal API token are unavailable. The owner has narrowed Due Good to a private local Tauri tool and requested everything visible to the signed-in Canvas account: download discoverable files and log links. The iCal-backed native store remains authoritative for calendar facts and local progress. The former native Canvas refresh requires a bearer token. A content-free 2026-09-27 probe found the dedicated Chrome profile signed out; live endpoint and page behavior remains unverified.

## Design

After a visible owner-managed sign-in to one dedicated Chrome profile, use the same credential-store configuration for headless Playwright capture. Keep cookies in Chrome: never save `storageState`, use Playwright's Node request context, log private content, or accept a caller-chosen origin. Allow only audited, fixed-shape GET API paths on the pinned Marymount Canvas origin. Do not navigate to content HTML, module item URLs, quizzes, or external tools because viewing may change Canvas state. Validate account identity, course IDs, JSON shape (including any Canvas anti-JSON prefix), pagination, redirects, response types, byte/item/time budgets, and completion. Inbox detail GETs explicitly set `auto_mark_as_read=false`. A signed-out or changed session produces a content-free failure receipt.

Discover every account-accessible course, including concluded courses when visible, plus account Inbox, profile, personal files, and accessible groups. Inventory course identity, syllabus/tabs, assignment groups and submissions/grades/comments/attachments, pages, modules/items, discussions and accessible replies, announcements, quizzes/calendar metadata, folders/files, and message attachments. Record unsupported or inaccessible areas as coverage gaps. Do not enter external LTI/publisher services, submit work, change read state, or bypass locked content. Log links with source/title/host and a safe non-secret URL: keep only reviewed public query keys for known hosts, otherwise omit query/fragment; omit path tokens for known sharing hosts. A redacted link remains a logged reference, not a clickable promise. Never persist signed Canvas URLs or fetch external links.

Three owner-provided private Canvas Print Grades PDFs are structural evidence for a possible Grades fallback. Their layout has wrapped rows, page splits, and interim totals; the existing synthetic triplet parser does not cover it. The captain inspects them locally, and any worker receives content-free structural notes only. Test a PDF fallback only if live Grades reads require it, using synthetic/redacted documents. Never infer missing scores or a final course grade from an interim total.

Resolve HTML file references to numeric Canvas file IDs and fetch file metadata through audited Canvas API paths; use the verifier URL in memory only. Pass a signed, cookieless URL to a dedicated Rust download helper through a private pipe, never a command argument or file. That helper reuses `src-tauri/src/downloads.rs` host allowlist, manual redirect checks, and no-Authorization client. If a file needs browser cookies or exceeds the verified download limit, record its ID and failure reason without silently claiming it downloaded. Validate byte count, hash, and MIME when available; deduplicate only verified bytes. File completion is a separate coverage dimension and never blocks current-term metadata publication. A downloaded blob is never rendered in the WebView. Native open is allowed only after content signature verification for an approved type; saved copies carry macOS quarantine metadata and a sanitized display name. Write to a private 0700 temporary root with 0600 files; clean on success, failure, and signals, and sweep stale owned roots on start.

Write a versioned private capture manifest last, with monotonic run ID, manifest hash, per-course/per-section observation and completion evidence, and content-free failure receipt. Strip verifier URLs from all nested HTML and file records before persistence. Native import rejects symlinks, stale IDs, schema mismatch, incomplete metadata, and any blob whose hash differs. Reuse the existing Canvas normalizer; add verified promotion of folderless iCal courses and a reconciliation rule that preserves an iCal due observation newer than the browser observation. Complete all configured current-term courses and required metadata sections before one atomic publication; historical courses belong in a separate archive. File and link gaps remain visible separately. On incomplete capture, retain the prior generation but write a private app-data attempt-status sidecar, outside the generation, before capture starts and on failure, so views become unverified even when no store publication occurs. The native importer merges against the latest store generation under the existing locks; an iCal conflict gets one bounded retry or a clear failure. iCal refresh remains independent. The personal operator CLI may collect using the source checkout; the signed Tauri bundle imports a validated fixed-location bundle and must not execute mutable checkout scripts.

Verified blobs move into a private content-addressed archive outside store generations under one native writer. On first import, migrate existing generation materials only after hashing and verifying archive copies; the next generation omits the duplicated material bytes. A restored snapshot with a missing blob reports a missing resource and never opens an unverified path. Archive references remain durable across snapshots and exports; automatic garbage collection is deferred, and a declared total disk cap stops new downloads with explicit per-file gaps. Archive writes use a private lock and atomic rename.

## Phases and gates

1. Build audited browser GET guards, reader, area inventory, sanitized link ledger, and manifest writer in bounded tasks. Add Rust downloader/archive helper as a separate bounded task. Synthetic tests cover sign-out, anti-JSON prefix, unsafe pagination, identity mismatch, size limits, redirect refusal, URL redaction, full completion, and cleanup. Gate local, typecheck, lint, deadcode, public-tree, and membership. A content-free attended sign-in probe establishes live feasibility.
2. Add native manifest/blob validation, atomic import, archive migration/resolver, failure sidecar, and per-course/section/file coverage projection. Synthetic tests cover malformed and partial input rollback, iCal collision, personal-state preservation, historical separation, missing blobs, and due provenance. Gate Rust, UI, deadcode, public-tree, and membership.
3. Expose the Tauri import/status workflow and keep iCal refresh distinct. Test desktop success, expiry, partial capture, and stale-data display. Run the staged full gate, then an attended live capture after owner sign-in. Apply to the real store only after complete validation. Installed-app behavior and owner acceptance are separate gates.

## Self-review and recovery

The chief failures are treating an SSO page, clipped list, or failed download as a complete empty capture, and inflating the generation store with copied files. Require identity, shape, end-of-pagination, and file verification; on failure leave authoritative data intact and visibly stale. No public student onboarding, Canvas mutation, or credential recovery is in scope. Prior plan reviews covered the narrower Grades/Inbox/Library metadata candidate; this expanded candidate needs review against its exact bytes.

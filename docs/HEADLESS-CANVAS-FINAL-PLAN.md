# Due Good personal whole-account Canvas capture — final implementation plan

## Evidence and authority

The owner has selected a personal, local Tauri tool. Marymount OAuth approval and a replacement personal token are unavailable. iCal remains the current-term calendar source and the native store remains authoritative for local progress. On 2026-09-27, one visible owner sign-in followed by separate clients and restarts of the persistent browser broker proved live session continuity and authenticated API shape. One file's metadata was accessible, but its verifierless URL returned `SESSION_REQUIRED` to a cookieless range request; native download remains unverified. No public login or cloud service is part of this work. Three private Print Grades PDFs were described as structural evidence by a peer task; this task cannot access them in Downloads and will not send them to a worker. A PDF fallback is conditional on live Grades need and local availability.

## Browser read contract

An owner signs in visibly to the fixed dedicated Chrome profile held by one persistent browser broker. Subsequent bounded commands attach through its owner-only Unix socket without closing the browser. A concurrent profile open fails with a clear status; a stopped process or expired Canvas session may require another owner sign-in. Only fixed-shape, audited same-origin Canvas API GET paths run inside the browser; no Node request context, cookie export, storageState, content-page navigation, module `html_url`, quiz attempt, or external LTI launch. Disable the browser HTTP cache for capture and use no-store requests; the collector must not persist response bodies or signed URLs in its own logs, manifests, or Git. Keep one collector/profile lock. Identify the account via Canvas's self endpoint. A first account has preview-only capture until the owner confirms its identifier locally; later captures must match that binding.

Discover all account-visible active and concluded courses, accessible groups, personal files, and Inbox/Sent/Archived conversations. Per course, inventory identity/syllabus/tabs, assignment groups and submissions/grades/comments/attachments, pages, modules/items, discussions/replies, announcements, quizzes/calendar metadata, folders/files, and linked file IDs. Keep historical and browser-only courses in a private archive by default. The authoritative current-term set is the native iCal course keys; a browser-only course gets stable `canvas-<numeric-id>` key/folder but joins the daily dashboard only after an explicit owner activation. The API allowlist enumerates exact path patterns and allowed query keys. Do not enter locked or unpublished content. A 401 or SSO response ends the capture; a 403 on a required active-course area marks metadata incomplete; a verified disabled optional area is a named gap. An unproven 404 is incomplete, never an empty result. Pagination must prove its end within byte/item/page/time budgets. Inbox detail uses `auto_mark_as_read=false`. Synthetic tests include Canvas's anti-JSON prefix and preserve unread state.

Parse HTML fields into bounded plain text and a separate link ledger; persist no raw HTML. Strip verifier and access URLs from all nested fields, including syllabus, page, discussion, announcement, message, file, thumbnail, and preview values. Log a link's source, title, ASCII hostname, and safe non-secret target. Retain only reviewed public query parameters for known hosts; otherwise remove query/fragment. Remove path tokens for known sharing hosts, labeling the reference non-clickable. External URLs are logged, never fetched. Captured API metadata is private and synthetic/redacted tests are the only fixtures.

## Download contract

Resolve Canvas HTML file references to numeric file IDs and in-browser file metadata. Keep a file download URL in memory only, passing it to a dedicated Rust helper through a private pipe, never arguments or a file. The existing Rust downloader streams into a 0600 staging file while enforcing its reviewed host allowlist, cookieless requests, and per-hop manual redirect checks. Live 2026-09-27 evidence shows one verifierless Canvas file requires the signed-in browser session; the cookieless helper cannot cover that file. Before implementing the browser-authenticated fallback, specify and test its fixed URL/redirect boundaries, private staging, and no-cookie-export behavior. Both paths reject sign-in/interstitial HTML, unexpected MIME/signature, unsafe redirects, and byte/disk limits. A local SHA-256 proves saved-byte integrity only; source authenticity remains unverified without a Canvas checksum. An oversized, authentication-dependent, or refused file is reported as a file coverage gap and does not block current-term metadata publication. No downloaded content renders inside the WebView. Native open requires a verified safe type; copies saved outside the app receive macOS quarantine metadata and sanitized names.

The collector owns a 0700 temporary capture root and cleans aborted roots on success/error/signals; it sweeps stale owned roots on start. A native helper stores a monotonic run counter and attempt-status sidecar in the fixed application-data root before collection begins. Its actual compiled binary is exercised by the local test gate. It stages files only. The collector atomically renames a finished private bundle into a fixed incoming location and writes its manifest last with a digest. It never puts unsigned or partially written bytes where Tauri imports. A pinned versioned JSON schema is checked by producer and consumer fixtures; unknown versions fail closed. The importer rejects symlinks, stale run IDs, changed account identity, malformed records, and blob hash mismatch. The durable archive has one native writer; only the validated import promotes staged blobs under an archive lock.

## Native publication, freshness, and recovery

Only an authoritative iCal-backed store accepts browser import. Preview and empty stores refuse it. Metadata for all configured current-term courses and required sections publishes in one short native generation transaction, merged against the latest store state. File/link gaps remain a separate coverage dimension. Keep prior generations on failed or incomplete capture. The app-data attempt-status sidecar is bound to run ID and generation, set to running before collection and failed on error/crash, and cleared to success only after native publication. The UI derives per-course/section freshness from that receipt, never from row counts or a global refresh timestamp. Current-term stale facts are hidden from the daily view; retained private snapshots remain available for recovery.

Reconcile Canvas by stable IDs, promote folderless iCal courses through verified course IDs, and create stable folders for browser-only courses. Preserve student checkboxes, notes, discussion checks, and manual grades. Compare actual source observation times before selecting a due fact. A legacy iCal due fact without a trustworthy observation time remains selected until a new verified iCal observation stamps it; do not invent a time. If iCal commits during browser collection, import merges from the latest generation and retries one bounded publication conflict. The last accepted run ID lives outside snapshot rollback.

On first import, copy and hash old generation materials into the content-addressed archive, then omit bulk bytes from new generations; preserve old generations unchanged. A prior file without a recorded source hash is not called source-verified merely because name/size match. Native snapshots hold archive references without duplicating blobs. A full owner export includes referenced blobs; after snapshot restore, a missing blob produces an explicit resource gap and never opens an unverified path. No automatic archive deletion is in this phase. A declared disk cap stops new downloads with named gaps rather than filling the host.

## Gates and live acceptance

Phase 1a builds the guarded reader and a content-free live probe with synthetic unit tests and headless `@playwright/test` browser coverage for login expiry, anti-JSON prefix, pagination/identity, and HTTP status categories. Before broad inventory, the owner signs in and the probe independently proves session continuity, authenticated API shape, account identity, read-state neutrality, and one file verifier/cookieless download. The streaming downloader can be built and synthetically tested in parallel because its safety contract is independent of that proof. A failed live probe holds dependent collection work and records a precise gap. Phase 1b then inventories current-term courses first, publishing complete current-term metadata independently of historical archive progress and file gaps; historical courses are resumable with per-course checkpoints and budgets. Test URL redaction and temp cleanup. Run local tests, typecheck, lint, deadcode, public-tree, and membership checks. Revise INV-5/7 and the refresh contract when the browser lane first lands, not at the UI phase. Phase 2 adds native validation/publication, archive migration/recovery, and coverage projection; test rollback, stale iCal ordering, new course identity, legacy hash handling, personal state, and missing blobs, then run Rust/UI/deadcode/public-tree/membership. Phase 3 adds Tauri import/status controls while keeping iCal Refresh distinct; run desktop tests and the full staged candidate gate. Extract clean seams from touched >800-line files in separate commits as required by the project charter.

After owner sign-in, the early content-free live probe must independently prove same-process session continuity, account identity, API shape/pagination, verifier availability/cookieless file download, and absence of unwanted read-state changes. Canvas may still record access or authentication telemetry for GETs; this tool claims no deliberate Canvas writes, not invisibility to the institution. A failed proof is an explicit gap, not an empty success. Real-store import needs a fully validated current-term metadata capture and owner-confirmed first account; installation, launch, live behavior, and owner acceptance are separate evidence gates. The signed Tauri bundle imports the fixed-location bundle and never executes mutable checkout scripts.
